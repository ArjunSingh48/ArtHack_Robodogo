# Performance content

| File | What | Edit? |
|---|---|---|
| `script.en.md` | the narration, chapter by chapter, with `@show` / `@hold` / `[pause]` cues | **yes** — artists own it |
| `lines.en.yaml` | short runtime lines (pose hints, consent, delivery caption) | yes |
| `catalog.yaml` | chapter, description, pose tags, interactive poses per artifact | yes (curators) |
| `records.yaml` | museum metadata of the 13 early artifacts | **no** — generated by `itu show catalog build` |
| `images/` | their images (The Met: public domain; Cleveland: CC0) | no — generated |

After editing: `itu show validate`, then `itu show voice pregenerate` (only changed lines are regenerated).
Another language: add `script.<lang>.md` and `lines.<lang>.yaml` with the same chapter ids and keys,
then `itu show --lang <lang>`.

Sources of the early artifacts (all verified 2026-10-24 through the museums' open-access APIs):
The Metropolitan Museum of Art — 327508, 545395, 329081, 323707, 467641, 464212, 471826, 283102, 265794,
285425, 266886; Cleveland Museum of Art — 169746, 290412. Links are in `records.yaml`.
